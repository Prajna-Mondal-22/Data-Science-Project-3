# OIBSIP_Data-Science_Task-No-05
Objective: Build a regression model that predicts product sales based on advertising spend across different media channels (TV, Radio, Newspaper)
<br>
Tech Stack: Python, pandas, scikit-learn, matplotlib, seaborn, Jupyter Notebook

The Sales Prediction project was successfully completed using machine learning techniques to predict sales based on the available features. The dataset was analyzed through exploratory data analysis, including missing value checks, descriptive statistics, scatter plots, and correlation analysis.
A Linear Regression model was used as the baseline model, and its performance was evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² Score. An additional regression model was also trained and compared to identify the better-performing model.
The results show that the selected features have a significant relationship with sales. The model with the lower MAE and RMSE and higher R² score was considered the best-performing model. The residual analysis was used to examine whether prediction errors were randomly distributed.
Overall, this project demonstrates how machine learning regression techniques can be used to analyze sales data and make predictions. The insights obtained from feature importance and model evaluation can help businesses understand the factors influencing sales and support data-driven decision-making.
